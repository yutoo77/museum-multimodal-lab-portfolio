# 科学館訪問：3〜5分の操作ガイド

これは**自作の架空資料による研究用デモ**です。実館資料・来館者情報は入れません。画像や音声をAIが完全に読めることを示す場ではなく、読み取り結果を人が確認し、後の質問で元資料へ戻れる一連の仕組みを見せます。

## 準備（訪問前）

1. [README](../README.md)の手順でアプリを起動し、`http://127.0.0.1:5174/`を開く。画面のローカルAI接続表示と`GET /api/health`を確認する。ポートが使用中なら、既存プロセスを終了させず原因を確認する。
2. `data/demo/fictional_lumina_table.png`、`fictional_sorano_guide.pdf`、`fictional_stardust_announcement.wav`を用意する。なければREADMEの生成手順を実行する。**どれも実在の科学館の資料ではない。**
3. 表画像・PDF・音声の抽出結果を原本と見比べ、必要な修正と登録を事前に済ませる。とくにWAVの元文字起こしは、以前の実機確認で固有名詞と時刻を大きく誤認した。修正後の内容を機械抽出の成功と説明しない。
4. 当日使う質問文を同じPCでリハーサルする。画像の読み取りは初回実装時の単発測定で106秒、今回の別条件での隔離実行では26.17秒だった。改修の速度効果を比較した実験ではないため、3〜5分の本編では登録済み資料を中心にする。待ち時間やモデル切替時間は保証値ではない。

## 本編の操作順

| 目安 | 画面で行うこと | 伝える要点 |
| --- | --- | --- |
| 0:00〜0:30 | 「保存した資料」を開き、表画像・PDF・WAVが同じ一覧にあることを見せる | 異なる形式を同じ知識の入口へまとめる。ただし一覧にあるだけでは検索対象ではない。 |
| 0:30〜1:45 | 「質問する」で「ルミナ水槽 LM-482 の水温は何℃ですか？」と尋ねる。回答案と出典カードから元画像を開く | 資料に固有の架空値`17℃`を、保存済みの確認済みテキストから検索する。回答文はその場のローカルモデルによる生成で、固定文ではない。 |
| 1:45〜2:40 | 音声資料の詳細を開き、元WAV・時刻付き抽出・修正後の文字を見せる | ASRは誤る。原本に戻って人が修正したテキストだけを登録する設計。実際に耳で再生確認できなければ「音が聞けた」と言わない。 |
| 2:40〜3:40 | PDF資料を開き、ページプレビューを見せる。余裕があれば「ソラノ光路の体験時間は？」と質問し、`23分`と1ページ目の出典を開く | 元ページへ戻れること、画像解釈・PDF文字・音声文字起こしの由来が異なること。 |
| 残り | 「資料を取り込む」で別の自作資料を選び、処理工程と確認・登録の導線を短く見せる | その場で100秒級の解析を始めた場合は、処理中であることを明示し、完了したふりをしない。 |

「事前に登録した資料を使ったデモ」と「その場で解析した資料」は口頭でも区別してください。登録済み資料への**質問はライブ実行**ですが、抽出結果そのものは事前処理済みです。モデル停止時に保存済みの内容やスクリーンショットを示す場合も、ライブ回答と呼びません。

## うまく動かないとき

- 画面が開かない：`start_demo.ps1`の出力、`data/logs/`、8765/5174/11436番の占有を確認する。他アプリのOllamaを停止しない。
- ローカルAI未接続：専用Ollamaと導入済みモデルを確認する。ネット接続のない会場でモデルを自動取得しようとしない。
- 読み取り・登録ジョブ失敗：資料詳細の失敗理由を示し、確認前の結果は検索されないことを説明する。必要なら事前登録済みの別資料へ戻る。
- 回答保留：根拠不足なら仕様どおり保留する。一般知識で無理に補完せず、元資料と検索対象の状態を確認する。

終了は`stop_demo.ps1`で**このアプリが起動した**プロセスだけを停止する。実館での利用や精度を保証するものではなく、職員の方には「どの資料・業務なら役立ちそうか」を聞く。

## 自分のPCで確認する7操作

1. `start_demo.ps1`で起動し、`http://127.0.0.1:5174/`を開く。
2. 「保存した資料」で、表画像・文字PDF・WAVの登録状態を確認する。
3. 表画像を開き、原本と抽出文・修正文を見比べる。
4. 「質問する」で「ルミナ水槽 LM-482 の水温は何℃ですか？」と入力する。
5. 回答案の出典から元画像を開き、`17℃`が原本に実在するか確認する。
6. PDFの元ページと、音声の時刻付き文字起こしをそれぞれ開く。音声の実再生は自分の耳で確かめる。
7. `stop_demo.ps1`で停止する。
