# Public切り替え前の安全監査（2026-11-14）

この文書は、2026-11-14時点のMuseum Multimodal Labの**公開前ソース候補**を監査した記録です。候補は当時のソース・設定例・文書・公開可能な画面画像だけを別フォルダへ取り出し、既存の開発履歴を引き継がない独立したroot commitから記録しました。元の開発用リポジトリは変更していません。現在の公開状態を示す文書ではなく、このリポジトリは2026-11-15にPublicへ切り替わりました。この記録は法的判断でも、個人情報や秘密情報が一切ないことの保証でもありません。

## 対象と除外

- 公開候補：ソース、依存定義、設定例、READMEと技術文書、自作の架空資料を使った画面画像。
- 除外対象：原本・SQLite DB、実行ログ、モデル、仮想環境、`node_modules/`、ローカルの検証出力、実館資料や個人データ。
- READMEの代表画像は[実Ollamaの回答画面](screenshots/answer-real-ollama.png)です。実モデルで撮影した画面とFake APIのUI検査画像は、ファイル名と[画面記録](UI_REVIEW.md)で区別します。撮影時の試行回数・修正内容・限界は[検証記録](../TEST_REPORT.md)を参照してください。

## この候補で実施した確認

- `git archive`から過去の`.git`を持ち込まず、履歴のない別フォルダで`main`を初期化。root commitに親はなく、初期化時の参照は`refs/heads/main`のみ、タグとremoteはありませんでした。到達可能な全コミットについてauthor・committerの名前とメールを照合し、GitHubで確認したユーザー名とnoreplyアドレスのみでした。Gitオブジェクト検査も成功しました。
- 公開対象はソース・文書・正式な`LICENSE`・PNG 13枚。DB、原本、モデル、ログ、`.env`実体、旧UIレビュー画像74枚、PCの詳細構成を記した内部の事前監査文書、5 MB超のファイルは含めません。代表画像13枚は架空資料のみの画面を目視確認し、PNG付加メタデータがないことを調べ、元の画像とSHA-256で一致するコピーです。
- 管理対象の文字列検査では、典型的な認証情報の形式、個人用ホームパス、旧開発コミットID、旧開発リポジトリの絶対URLは見つかりませんでした。メールアドレスに見える文字列は、テスト内の配達不能な予約ドメイン1件のみです。README・文書のローカルリンク54件はすべて解決しました。
- 公開候補の新規仮想環境で`pytest -q`は68件成功、Ruff・compileall・`pip check`も成功。`npm ci`の依存監査では報告0件、Frontendの型チェック・Lint・Buildも成功しました。今回の公開候補では重い実Ollama E2Eを再実行していません。実モデルの画面は過去の隔離検証によるもので、現在のテスト結果と混同しません。

これらは**公開前の技術的確認**です。`.gitignore`の存在だけで安全とは判断しません。

- GitHub APIで新リポジトリのPrivate設定、`main`のみのブランチとタグ0件、ローカルと一致するHEAD、管理対象69ファイルの完全一致を確認しました。GitHub上の`LICENSE`はGNU公式の34,523バイトと同じ内容で、READMEと実Ollama代表画像のblobもローカルと一致します。GitHubがレンダリングしたREADMEに画像のHTML要素があることを確認しました。

Privateでの確認はPublic可視性での閲覧を実証しません。Publicへ切り替える直前に、その時点の変更・権利帰属・公開設定を本人がもう一度確認します。

## 公開直前に照合すること

1. 新しい履歴が単一のroot commitから始まり、別のブランチ・タグ・参照から開発履歴へ到達できないこと。`git log --format=fuller --all`でauthorとcommitterの両方を確認し、GitHubユーザー名と**確認済みのnoreplyアドレス**以外を含めないこと。
2. Git管理対象の全文・ファイル名・画面画像・PNGメタデータに、認証情報、個人情報、ローカル絶対パス、実館資料、DB、ログ、モデル、原本が含まれないこと。過去の開発用コミットへの参照も公開文書に残さないこと。
3. READMEと文書の相対リンク、実Ollama画像の実在、依存定義とセットアップ手順、Backend/Frontendのテスト結果を、公開候補の内容で確認すること。以前の環境で通ったテストを、候補で通った結果と言い換えないこと。
4. 新しい独立リポジトリ`museum-multimodal-lab-portfolio`を最初はPrivateで作り、push後の履歴・README・画像・可視性を確認すること。Publicへの切り替えは利用者本人の最終確認まで行わない。
