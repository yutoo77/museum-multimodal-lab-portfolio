# 公開時の確認事項

このリポジトリは、科学館向け研究プロトタイプの公開ソースです。今回の反映では、既存の公開履歴を起点に実装・依存関係・起動手順・回帰テストだけを選び、別環境で確認しました。開発用の履歴、評価用資料・質問・ログ、内部監査記録は含めません。

- デモ素材は架空の資料をローカルで生成します。公開用画像はアプリ画面だけを撮影し、掲載前に画面内の情報とPNGメタデータを確認しました。
- 原本、DB、Qdrantの索引、ログ、モデル重み、アクセス情報はリポジトリに含めません。ローカルの配布物は公開ソースとは分けて保管します。
- 自作ソースの[AGPL-3.0-only](../../LICENSE)は維持します。[第三者ライセンス通知](../../THIRD_PARTY_NOTICES.md)に別取得するモデル・依存と、保持すべき提供元の通知を示します。
- [動作確認](../TEST_REPORT.md)は少数の架空資料と自動回帰に限定します。科学館での実運用、一般的な検索・回答精度、ネットワーク遮断下での完全オフライン動作は実証していません。
- 公開検証環境の依存を `pip-audit`（Python 53件）と `npm audit`（ロックの145依存）で確認し、監査時点では既知警告0件でした。Pythonのバージョン範囲全体や非同梱のOllamaバイナリまで安全と保証するものではありません。

変更を公開するときも、差分と履歴の著者・コミッタ情報、画像、通知、依存の状態を再確認してください。ここでの確認は今後の追加素材・依存関係まで保証するものではありません。
