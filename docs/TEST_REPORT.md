### 初回実装時に実モデルで観測した各経路

専用Ollama 11436番、Backend 8765番、Frontend 5174番の起動と`/api/health`応答を確認しました。自作の`fictional_lumina_table.png`を入力すると、導入済み`qwen3.5:2b`が表の`17℃`、`42 L/分`、識別番号`LM-482`を抽出しました。周辺文言は原本の「実在」が「実際」に変わる小さな誤読があり、無修正で原文と同一とはみなしません。抽出テキストを確認・修正して登録しました。登録前の質問は`held`、登録後の質問では`qwen3:4b-instruct-2507-q4_K_M`が`17℃`を含む回答を返し、出典は実在する`image_interpretation`のUnitと元画像URLに結びついていました。埋め込みは`embeddinggemma`です。

この一往復は**画像→修正→索引化→RAG回答の実動作**を示しますが、テスト操作は科学館職員・専門家による確認ではありません。表全体の正確率、他の画像への一般化、出典と回答の意味的整合性を保証しません。時間はこのPC・この1回の観測で、モデル切替や負荷の影響を分離していません。GPU使用量は`nvidia-smi`の瞬間値で、ピークVRAMは未測定です。

テキストPDF`fictional_sorano_guide.pdf`はPyMuPDFで1ページを抽出しました。原本の日本語フォントから互換漢字が現れたため、テスト操作で標準的な日本語へ修正・登録しました。登録前の質問は`held`、登録後は「体験時間は23分」に対応する回答案と`pdf_text`・1ページの出典が返り、元PDFの`#page=1`へ進めるURLを確認しました。抽出ジョブの記録値0秒は秒単位の丸めを含み、処理時間がゼロだった意味ではありません。

WAV`fictional_stardust_announcement.wav`はローカルのfaster-whisper `tiny` / CPU INT8で1セグメント（0.0–6.0秒）に文字起こしできました。しかし**元ASRは展示名と時刻を大きく聞き違えた**ため、テスト操作で「星くずドーム…午後3時40分」に修正して登録しました。比較用の`base`も同じ合成音声の固有名詞・時刻を大きく誤認しました。登録前の質問は`held`、登録後は修正後の`午後3時40分`を含む回答案と`audio_transcript`の時刻付き出典、元音声の`#t=0.00` URLを確認しました。これは編集後の知識が使われた証拠であり、元ASRが正しかった証拠ではありません。科学館職員の校閲や実音声環境での性能評価ではありません。

### 再起動・資料外質問・差替え

`stop_demo.ps1`で停止し、`start_demo.ps1 -NoBrowser`で専用Ollama・Backend・Frontendを再起動できました。再起動後に架空表画像の質問を繰り返すと`17℃`と正しい画像出典が返りました。これは少なくともこの1件で、保存済み原本・索引を再起動後も参照できたことを示します。

実資料を読み込んでいない状態で「名古屋市科学館の開館時間」を尋ねると`held`となり、出典は0件でした。これは資料外質問1件の保留例であり、すべての資料外質問を拒否するという保証ではありません。

同名の架空PDFをもう一度アップロードするとversion 2が作成され、version 1の索引は即時無効化されました。新版の承認前の質問は`held`、新版の再抽出・修正・承認後の質問は`23分`と回答し、出典はversion 2のDocument IDだけでした。一覧にはversion 1が`superseded`として残り、閲覧・削除は可能です。旧資料・原本を物理的に消したわけではありません。この確認もPDF1件のAPIスモークです。

元WAVのHTTP `Range: bytes=0-99`要求は`206 Partial Content`と`Content-Range: bytes 0-99/275332`を返しました。音声の区間取得を支えるHTTP応答は確認できました。Playwrightの画面操作では、3タブ間の移動、旧版を含む保存資料4件、旧版の抽出操作が無効なこと、表画像の原本プレビューを確認しました。Backend再起動後の最終UIスモークで、画面から「ルミナ水槽の水温は何℃」と質問すると`17℃`と出典1件が表示され、出典リンクから原本へ進めました。質問操作の計測値は15.28秒です。この1回の時間を通常速度とはみなしません。PDF version 2の1ページは、Backendがローカル描画したPNGとしてHeadless Edge内に可読表示され、元PDFリンクもHTTP 200でした。音声コントロールとシークUIの表示も確認しましたが、実際の音の再生は未確認です。ブラウザーでの新規アップロード・修正・承認、削除は通しで確認していません。スクリーンショットと操作結果はGit管理外の`outputs/ui-smoke/`に保存しました。

## 接続・安全性の検査範囲

アプリのOllamaクライアントはloopback URLに制限し、環境プロキシとリダイレクトを使いません。起動スクリプトはFrontend/Backend/専用Ollamaを`127.0.0.1`へバインドし、既存の11434/11435番を占有せず、一時的に変更する起動用の環境変数を復元します。外部AI APIへの自動フォールバックはコードに設けていません。異なる`Origin`または`Sec-Fetch-Site: cross-site`を伴うPOST/PATCH/DELETEを403にするAPIテスト、巨大PDFページを画像モデルへ送る前に長辺1280ピクセル以下でラスタライズするfakeテスト、生成中に引用Chunkが編集・削除・同名差替えされたら`held`にするfakeテストが通りました。Backend再起動後にも、外部`Origin`付きPOSTが403となることを確認しました。これらは**コード上の局所的な検査**で、認証や厳密な同時処理の原子的保証ではありません。**OS・ブラウザー・Ollamaプロセス全体のネットワーク遮断も証明しません**。切断したネットワークでの実行、通信キャプチャ、科学館実機での動作は別途確認が必要です。
